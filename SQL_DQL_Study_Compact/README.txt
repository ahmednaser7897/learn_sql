SQL SERVER DQL - COMPACT STUDY SET

The original DQL examples are preserved and formatted more compactly. Related concepts are split into six files. Non-DQL sections removed: USE DATABASE, VIEWS, SELECT INTO, INSERT INTO SELECT. Exact duplicate table-alias content at the end was omitted because it adds no new concept.

01_SELECT_FILTER_SORT.sql - SELECT, aliases, DISTINCT/TOP, WHERE, operators, IN/BETWEEN/LIKE/NULL, ORDER BY, calculations.
02_FUNCTIONS_AGGREGATION.sql - string/numeric/date/null functions, CAST/CONVERT, CASE, aggregates, GROUP BY/HAVING and related aggregation patterns.
03_JOINS.sql - INNER/LEFT/RIGHT/FULL/CROSS/SELF/multiple joins and join-based calculations/aggregation.
04_SUBQUERIES_SET_CTE.sql - subqueries, correlated queries, EXISTS/ANY/ALL, UNION/INTERSECT/EXCEPT, CTEs.
05_WINDOW_PAGINATION.sql - ROW_NUMBER/RANK/DENSE_RANK/NTILE, LAG/LEAD, FIRST/LAST_VALUE, OVER, frames, running totals, moving averages, TOP N per group, OFFSET/FETCH/pagination.
06_SYSTEM_QUERY_EXECUTION_EXAMPLES.sql - system-table queries, query execution order, templates, practical DQL examples, cheat sheet and final review.
